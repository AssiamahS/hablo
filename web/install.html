Hablo

🇺🇸 English ⇄ Spanish 🇪🇸 — translate as you type, in every app.

Install on this iPhone
Install
  1. Open this page in Safari on the iPhone.
  2. Tap Install, then Install on the iOS prompt.
  3. It lands in the App Library (search “Hablo”).
Set up
  1. Open Hablo → Download English & Spanish (offline after).
  2. Settings → Hablo → Keyboards → turn on Hablo.
  3. In any chat, tap 🌐 → type → Insert.

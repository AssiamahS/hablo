# Hablo

Translator keyboard for iPhone. Type in English, send Spanish (or the other way), in any app.

- **On-device translation** with Apple's Translation framework (download English + Spanish once in the app, works offline).
- Online fallback (MyMemory) only when the models are missing and Full Access is on.
- Compose card shows what you typed and the live translation; **Insert** drops the translation into the text field.
- **Translate field** button rewrites whatever is already typed in the host field.
- Swap languages with one tap; `ñ` key and `¿ ¡` when typing Spanish.

Install (registered iPhones): https://assiamahs.github.io/hablo/install.html

Built only in CI (`macos-26`, XcodeGen, iOS 26). `project.yml` is the source of truth.
